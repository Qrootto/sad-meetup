# DECISIONS.md — sad-meetup

**Назначение:** действующие решения, которые ограничивают будущую работу и не
видны из кода, токенов и конфигов — файл состояния (правила 6.5 и 6.6
глобального CLAUDE.md). **Потолок — 20 КБ** (по умолчанию; проверка —
`node tools/check-docs.mjs`).

**Как вести:**
- группы по темам; одна строка: правило — почему (если неочевидно) — (номер, дата);
- перед записью нового — найти и обновить существующую строку;
- отменённое и заменённое — удалить, не помечать; история — архив
  `docs/decisions/ГГГГ-ММ.md` (по умолчанию не читается);
- правило уже есть в CLAUDE.md проекта или другом файле правил — не дублировать, сослаться;
- потолок превышен — сначала ужать, потом писать.

## Стек и устройство

- Уровень проекта — см. CLAUDE.md проекта (2026-10-29).
- Ванильный JS + Vite, без фреймворка и других зависимостей — задача 1 (2026-10-29).
- Витрина читает исходный CSS (`?raw`) и разбирает его сама: связи, подписи,
  «где используется» нигде руками не ведутся (2026-10-29).

- Превью блоков и элементов в витрине — из `index.html`, масштаб по ширине
  области (ширина / 1440, в JS), без горизонтального скролла (2026-10-29).

## Лендинг

- FAQ — нативный `details`, можно открыть несколько; атрибут `name` не ставить (Q3, 2026-10-29).
- Подписка — проверка в браузере без отправки; ошибка — alert у поля, успех —
  форма сменяется сообщением (2026-10-29).
- Строки карточек тарифов — общий subgrid на пять строк: тег не сдвигает контент (2026-10-29).

## Токены

- Перерыв в программе — без тега, текст `--text-neutral-secondary`; у светлого
  тега два статуса: история — neutral, воркшоп — accent (2026-10-29).
- Текст на inverse — `--text-inverse-neutral-primary`, пара к
  `--text-neutral-primary` для тёмной темы (Q1, 2026-10-29).
- Тексты поля — роли: primary — ввод, secondary — плейсхолдер (Denim),
  tertiary — сообщение об ошибке (2026-10-29).
- Успех подписки — сообщение формы в подвале, не статус поля (Q4, 2026-10-29).
- Размер кнопки один — `--size-m`; второй — отдельной задачей (Q6, 2026-10-29).
- Ширины — токены без элемента: `--width-container`, `--width-nav` (2026-10-29).
