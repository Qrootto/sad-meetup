## Устройство дизайн-системы

- `src/tokens/primitives.css` — только `--p-*`; `src/tokens/tokens.css` —
  токены, каждый = один `var(--p-…)`; цвет — колонка Light на `:root`,
  Dark — `:root[data-theme="dark"]` (пока пуст).
- `src/components/<имя>.css` — компонент; `<имя>.demo.js` — разметка
  вариантов для витрины (тексты из content.md).
- `src/blocks/<NN-имя>/` — блок лендинга: `<имя>.css` — сам блок, остальные
  CSS — его элементы. Витрина подхватывает папку сама, порядок — по NN.
- `src/styles.js` — единая точка подключения стилей (globs).
- `library/` — витрина: `model.js` разбирает CSS, `draft.js` — черновик.

## Соглашения CSS (на них держится витрина)

- Шапка файла: `/* @title Имя  @description Что делает. */`.
- Одно объявление на строку. Редактируемое значение — ровно `var(--…)`.
  Подпись свойства — комментарием в той же строке; это единственный источник.
- Вариант — модификатор `.<имя>--<вариант>`; часть — `.<имя>__<часть>`.
- Стейт — пара селекторов: живой (`:hover:not(.no-hover)`, `:active`,
  `:focus-visible`) и принудительный `[data-state="…"]`.
- Цвет — только свойства `background-color`, `border-color`, `color`,
  `outline-color` (кольцо фокуса).
- Вложенный компонент в блоке упоминается селектором (`.price-card .button`) —
  из этого собираются «Состоит из» и «Используется в».
- Hover: вход мгновенно (`transition: none` на `:hover`/`:active`), уход —
  `--hover-out` + `--hover-easing` (правило 5.2).

  на живом Windows не смотрели.
